# MINING 规则基线

更新：2026-10-30。采用攻略大百科的“操作、事件与加时”组织方式，以 GameWith 与 Pocket Tactics 交叉核对；用户的实机说明作为独立证据保留。该文档是本项目的规则基线，**不是官方完整规则规范，也不是所有参数已经实测的声明**。

补充复核：现以日文 Splatoon RAIDERS Wiki 作为综合机制底稿，继续用上述操作表与实况交叉核查。Wiki 明确将 MINING 得分与前进距离关联，并描述配置随机及成组加时收益；没有给出精确运动与生成公式。[5] 核查范围与局限见 [日文来源比较](JAPANESE_SOURCES.md)。

## 碰撞和强化

| 事件/状态 | 采用内容 | 依据与状态 |
|---|---|---|
| 普通撞墙 | 角色停止，应避开道路两侧 | 用户与 [2][3] 一致；采用 |
| 普通撞石头 | 会停止 | 用户与 [2][3] 一致；采用 |
| 吃卵 | 进入加速/强化状态，强化时撞石头不停车，可以破坏石头 | [1][2] 与用户一致；采用 |
| 强化撞墙 | 仍会停下，墙仍是不可行驶区域 | 用户明确说明；保留。“无敌”不能推导成能够穿墙 |
| 普通撞石头后是否碎 | **未定** | 用户观察为“停且碎”；[1] 正文写吃卵后可以破坏此前不能破坏的石头，存在潜在冲突；不覆盖用户观察，也不把任一说法写成已核实事实 |
| 强化持续时间 | 攻略给出“约 10 秒” | [2] 的近似值；仅作参考，不能作为精确倒计时常量 |

## 加时、计分和评级

| 事件 | 数值或机制 | 采用状态 |
|---|---|---|
| 普通加时拾取物 | 每个 +1 秒 | 用户、[1][2] 一致，采用 |
| 强化期间撞碎石头 | 每块 +1 秒 | [1][2] 一致，采用 |
| 拾取红卵本身 | +2 秒 | [1] 的表格与本地实况约 00:39.75 后的 `+2.0` 提示一致；采用，观察记录见 [LOCAL_VIDEO.md](LOCAL_VIDEO.md) |
| 计分 | 随挖掘进度/深度增加 | 用户与 [2][3] 的概要相容；精确函数未知，不假定线性比例 |
| A 级参考目标 | 6000 分 | [1][2][3] 一致；作为参考目标采用，不作为运行停止条件 |

普通拾取物在攻略中分别称“青コイン”“ウズシオのかけら”“Spirhalite shards”，用户按画面称其为“白色星星”。本项目统一称**加时拾取物**，名称不同不代表已经核实其视觉外观。[1][2][3]

精确碰撞停顿时长、基础/强化速度、加速度、转向响应、深度到分数的公式：**未能检索到有效信源**，保持未知。运行中应读取画面状态，不能用攻略中的近似值替代观测。

## 如何用于软件

已采用规则同步保存在 `rules/mining.json`，每条记录保留来源与状态。默认基线仍以通道检测为约束；新增可选的多步规划器比较完整可达路线和整组加时收益，始终保留墙约束、强化下界与时间顺序。见 [核心 AI](MINING_AI.md)。此处策略选择属于工程推断，不能等同于已经验证的高分解法。

已用本地视频核验吃卵本身的 `+2.0` 提示。后续核验重点是普通撞石、强化碎石加时和强化结束，分别记录事件前后帧及 HUD 读数。视频中某次成功的分数只能证明该局结果，不能单凭结果推断精确评级下界或因果机制。
