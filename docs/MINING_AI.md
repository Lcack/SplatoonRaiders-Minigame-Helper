# MINING 核心 AI

当前实现是**可解释的短时域路线搜索原型**。下面的优化目标和建模方法属于工程推断；合成评估中的物理数值都是显式假设，不是实机测量值。

## 目标与方法

按当前可见道路展开左右及加速/松开加速的动作序列，选择满足模型约束、价值最高的一条，并只执行第一步；下一帧重新规划。每一层保留有限数量的候选，属于束搜索。搜索宽度、时域与节点数都有限，因此不保证找到模型的全局最优解。

模型价值定义为：

```text
前进深度 + 时间价值权重 × 唯一目标的加时总收益 − 转向变化惩罚
```

价值的单位是本模型的效用，**不是游戏 SCORE**。时间价值默认使用普通前进速率作为启发式换算，可用 `search.time_value` 调整；真实的最终分数收益和剩余时间价值仍需通过实机记录拟合。距离计分及加时规则的依据见 [规则基线](MINING_RULES.md) 和 [日文来源调查](JAPANESE_SOURCES.md)。

当前约束和功能：

- 逐段检查道路包络及墙，支持没有共同 x 交集的弯道；检查经过的道路折点和玩家尺寸。
- 石头与道路边界分开；普通碰撞损失时长未知，当前避石而不模拟“故意撞石换收益”。
- 对可达加时物 +1、红卵 +2、已确认强化内碎石 +1 做唯一目标累计，不能在多个时间步重复计入。
- 按接触顺序扣时间和加时，到时后才碰到的物体不能倒过来续命。
- 有效强化按已确认的剩余时间下界处理；不把攻略“约 10 秒”当精确结束时间。未知或不足一个规划步则等待观测，较短但有效的下界会缩小搜索时域。
- 强化前进速率 `boost_speed` 独立于普通/ZR 速率；涉及卵时缺少该模型就不输出新规划输入。
- 将延迟期间的横向不确定性膨胀到碰撞包络中；节点预算耗尽或完整时域无解时，不执行半成品路线。

## 使用入口

直接运行离线评估：

```powershell
python run.py mining-evaluate
```

默认输出 `artifacts/mining_evaluation.json`。7 个固定合成场景包括直路、S 弯、成组加时、单颗对照、强化石头、普通避石和墙堵路。报告保存假设、路径、预计加时、模型价值、展开节点数与本机耗时；这些数据不等同于实机成绩。

可运行 `python tools/plot_mining_evaluation.py` 生成中文路径示意图 `artifacts/mining_evaluation.png`。

旧基线保持默认。要在某份视觉 profile 里启用新算法，`policy.algorithm` 设为 `lookahead`，提供 `policy.motion` 与可选 `policy.search`。缺少模型或 `motion.calibrated` 不为 true 时，新算法只返回等待状态。实机输入还需原有的 profile 校准、实时源和手动启用控制门槛。

所需运动参数（速度单位为游戏区宽/高每秒）：

| 字段 | 含义 |
|---|---|
| forward_speed | 松开加速时的前进速率 |
| accelerated_speed | 按加速时的前进速率 |
| lateral_speed | 横向满量程移动速率 |
| boost_speed | 强化时独立的前进速率；当前模型不再区分强化中的按键档位 |
| latency_seconds | 输入到有效画面反馈的延迟估计 |
| uncertainty_x / uncertainty_y | 位置误差，需覆盖检测和离散化误差 |
| egg_buff_lower_bound_seconds | 吃卵后的已测有效持续时间下界 |
| calibrated | 上述模型是否已经实测 |

当前强化状态还需观测器输出 `metrics.buff_remaining_lower_bound_seconds`。它必须来自可靠的事件计时/状态估计；本轮没有伪造该读数。可选 `metrics.forward_speed` 给出当前速率，用于输入延迟阶段。

视觉层新增 `corridor` 检测器的 `fill_obstacles: true`：只恢复被可靠识别的石头覆盖的内部道路缺口，既不扩展道路外边界，也不填未知区域或墙。仍需真实模板与道路颜色配置，不能仅靠此选项获得可靠实机分割。

## 当前边界

速度是分段常数近似；一步中途吃卵时会按接触事件切分、立即重算余下时间的强化速度与扫掠碰撞，尚未拟合完整加速度和惯性。道路层之间插值也是模型假设；观测稀疏或错误时不能保证真实道路安全。需用更密道路层、误差包络及闭环反馈验证。

合成场景已经表明窄搜索可能漏掉更好的成组奖励，因此搜索宽度存在速度与质量取舍。每次重规划的目标只在可见短时域内，不能替代长期随机生成模型。未来的计分、耗时和仿真参数都应带测量来源与版本。

完整实况可以检验视觉误差和几何建议，但录播不会响应 AI 的反事实操作，所以**不能用固定录播给 AI 测实机得分**。后续需要：人工标注片段检验识别 → 实机短脉冲测控制响应 → 校准闭环 → 多局分数分布和消融对照。若再考虑强化学习，首先仍要有可信的交互环境与奖励观测；当前先使用规则与搜索原型。

声明分类与置信度：模块能力和评估输出属于客观事实，高（≥80%）；优化目标、启发式与后续路线属于逻辑推断，中（50–80%）；合成物理值属于推测假设，低（20–50%），不作为实机事实。实机最高分与全局最优性未知。
