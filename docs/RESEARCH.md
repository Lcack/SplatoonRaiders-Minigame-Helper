## MINING：用户提供的当前规则

以下来源是本次会话中的用户说明，优先用于本项目的需求定义：

- 左右两侧不可行驶，撞墙会停；只有中间道路可走。
- 撞石头会停，石头会碎。
- 左上白色倒计时从 40 秒开始；到零结束。
- 右上角为分数，挖得越深分数越高。
- 路上白色星星每个增加 1 秒。
- 鲑鱼卵使角色加速，强化时撞碎石头不减速且加秒；仍然会撞墙停下。
- 强化持续时间、撞碎一块石头增加几秒、距离到分数的公式、碰撞停顿长度：未知，不填常数。

工程推断：墙必须是不可通行约束，石头则是随强化状态改变代价的对象。优先在道路中延长有效行驶时间；强化期间可将石头计入收益目标。当前原型仅做短距离扫描线通道与代价比较，还没有完成弯道运动规划。

## 来源可支持的最小规则摘要

任天堂开发者访谈确认基地船内存在 2D 小游戏，并提到画面模仿 CRT 的表现。[1]

日文 GameWith 与英文 Pocket Tactics 都列出 MINING、HOPPING、JUGGLING、LANDING 四项。可支持的概要是挖掘、保持乌贼弹跳、双角色接抛、飞行着陆四种玩法。[2][3]

二者对 JUGGLING 的 A 级分数分别给出 8000 与 7000，对 HOPPING 的碰撞扣时也不一致。因此所有评级门槛、精确扣时均不写入自动策略。当前没有找到足以消除这些冲突的官方规则表。[2][3]

## 公开视频

已打开并实际观看 UTAGaming 的无解说实况，使用游戏画面和屏幕按钮提示作为一手观察材料，不采纳评论区或标题的攻略判断。[4]

视频简介中的章节：

| 时间 | 游戏 |
|---|---|
| 00:00 | MINING |
| 05:25 | HOPPING |
| 11:03 | JUGGLING |
| 16:03 | LANDING |
| 20:33 | Credits |

已观察：

- MINING 约 00:12：中央道路、两侧黑色不可行驶区域、岩石、左上 TIME、右上 SCORE；底部明确显示 ZR Accelerate、左摇杆 Move。
- HOPPING 约 05:37、08:35：地面机器人、空中的乌贼与多个敌人；底部显示左摇杆 Move、B Jump。08:35 时可见 TIME 60.8，这只证明该帧显示值，不据此推断初始时间。
- JUGGLING 约 11:06：画面下方两个角色和中央隔板，上方生命心形及分数；底部显示 ZL/ZR Slide、左右摇杆 Move。原型据此预留滑步并将接球目标按左右区域分配，隔板的精确碰撞行为仍待连续帧核对。
- LANDING 约 16:23：左侧为机器人起飞台、右侧为乌贼所在的平台，中间有竖向障碍；底部显示 ZL Left Jet、ZR Right Jet 和 STAGE 02/10。该帧支持左右喷射独立输入的接口设计，不足以反推出推力、转动惯量或风速。

2026-10-29 进行的是关键片段观察，当时没有下载或逐帧量化整段视频，没有训练视觉模型。视频截图中有扫描线、色彩边缘与频道水印；未来模板应避开水印，保留视频时间、游戏阶段、ROI 和采样分辨率。网页上的实际游戏画面比网页正文更适合核对按键提示，但仍不能给出用户采集卡的输入延迟。

## 实现顺序（工程推断）

1. 先用公开视频抽取开始、运行、碰撞、强化、结束等片段，制作人工标注；不要把相邻帧随机拆分为训练与验证集，应按完整片段或对局划分。
2. 优先做 MINING：道路掩膜 → 角色与石头 → 星星与卵 → 强化 → 倒计时/分数 → 通道规划。
3. 通过录像中的位移拟合局部速度；通过真实输入与采集反馈测得转向与延迟，再启用控制。
4. HOPPING/JUGGLING 增加重力、反弹和多目标轨迹，LANDING 独立处理角度、双侧推力、风和落地速度。
